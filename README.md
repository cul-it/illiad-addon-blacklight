# Blacklight OPAC Search addon

## Overview

The Blacklight OPAC Search is an ILLiad add-on that allows the windows ILLiad client access to the Cornell blacklight catalog providing a simple way to import item record information into the request details.

## Installation

1. Clone the repository to your local machine.

2. Move or copy the created directory to your ILLiad add-ons directory.

3. Restart the ILLiad client.

## Configuration

In the ILLiad client `Manage Addons` window, find the Blacklight OPAC Search in the list of add-ons and click the Active checkbox. The default settings:

- `OPACURL`: The URL for the catalog, defaulted to https://catalog.library.cornell.edu

## Usage

1. Open a request, click the Blacklight OPAC Search tab

2. The browser should load the library catalog. The Search buttons in the ribbon will allow you to search for the item various ways from the information in the request details (Author, Keyword, Title). Once you are on an item record, clicking the 'Import Info' or 'Import as E-Resource' buttons will switch you to the Details tab.

3. In the details pane, the newly imported information will be highlighted in yellow.
